# epocrates Growth Audit

**Live → https://eddieatadapty.github.io/epocrates-flow-rebuild/**

Five ideas to turn more epocrates users into subscribers, each built into a clickable version of epocrates's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Open on the tool they came for | +10–20% CR to purchase |
| 02 | Name it on the paywall | +15–20% CR to purchase |
| 03 | Ask one thing the ad didn’t answer | +10–15% CR to purchase |
| 04 | Put clinicians’ words where they decide | +10–15% CR to purchase |
| 05 | Make the annual saving impossible to miss | +5–15% CR · ARPU +10–15% |

Every price, rating and feature comes from epocrates's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for epocrates. They overlap, so they don’t add up. Nothing here is a claim about clinical outcomes.

Static single page, no build step: `python3 -m http.server`.
